# Midnight Syntax

**Built in the dark. Crafted with intent.**

Midnight Syntax is an independent game studio exploring the space between **code, systems, art, and play**.

We build digital worlds with a focus on strong ideas, robust technology, precise design, and the small details that make an experience feel alive.

## What lives here

This repository contains the public GitHub profile and shared community resources for Midnight Syntax.

Across our repositories you may find:

* games and experimental projects
* internal tools released for public use
* technical prototypes
* libraries and reusable systems
* documentation and shared engineering standards
* open-source work we believe may be useful to others

## How we build

We care about software that is deliberate rather than disposable.

That means:

**Strong foundations.**
Code should remain understandable when a project becomes larger than expected.

**Precision over noise.**
Complexity should earn its place.

**Technology in service of experience.**
The best engineering disappears into the thing it enables.

**Craft matters.**
Architecture, interaction, visual design, sound, performance, and tiny details are all part of the same product.

**Different by design.**
We would rather make something with a clear identity than follow a template.

## Open source

Public repositories are maintained individually and may use different licenses.

Please check the `LICENSE` and contribution guidelines of the repository you are working with before using or contributing to a project.

## Security

If you believe you have discovered a security issue, please avoid opening a public issue.

Use the security reporting instructions provided in the affected repository whenever available.
